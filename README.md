# NoBot

一个轻量、快速的 AI 角色扮演 / 陪伴 / 跑团应用，长对话也不卡。

- **兼容酒馆（SillyTavern）**：角色卡、世界书、生成预设、立绘包、快速回复直接导入，导出的角色卡酒馆也能读
- **视觉小说（VN）模式**：模型写舞台指令，界面逐句演出立绘、背景、CG、BGM、选项和状态面板，台词可以配音朗读
- **多用户**：每个账号的数据完全隔离，适合部署在家里的服务器上给家人朋友用
- 界面支持中文 / English

## 快速开始

需要 [Bun](https://bun.sh) 1.4 以上（macOS：`brew install oven-sh/bun/bun`）。

```bash
bun install
NOBOT_ADMIN_PASSWORD='至少8位的密码' bun run dev   # 第一次启动时创建管理员账号 admin
```

浏览器打开 <http://localhost:5173>，用 `admin` 和刚才的密码登录。管理员创建好之后，以后直接 `bun run dev` 即可。
想换管理员用户名，再加上 `NOBOT_ADMIN_USERNAME=名字`。

登录后左边一列是导航，按顺序配一遍：

1. **连接**：选提供方（Claude、Gemini、Vertex AI、Azure 走原生接口；OpenAI、DeepSeek、OpenRouter、Ollama 等三十多家预填好地址；中转站选「自定义」），填 Key 后测试并拉取模型。常用的连接 + 模型 + 预设组合可以存成「配置组」
2. **人设**：改成你想在故事里用的名字（角色卡里的 `{{user}}` 会替换成它）
3. **角色**：导入酒馆的 PNG / JSON 角色卡，或者新建一个；卡里自带的世界书会自动导入
4. **聊天**：点角色 →「新建会话」；点「群聊」可以把几个角色拉进一个群

### 日常使用（生产模式）

```bash
bun run build   # 打包前端，代码更新后执行一次
bun start       # 单进程，打开 http://127.0.0.1:3000
```

同一局域网的手机访问：`HOST=0.0.0.0 bun start`，手机打开 `http://电脑的局域网IP:3000`。
要放到公网上，请在前面加一层 HTTPS 反向代理（Nginx、Caddy 等），不要直接暴露 3000 端口。

### Docker 部署

```bash
echo "NOBOT_ADMIN_PASSWORD=至少8位的密码" > .env
docker compose up -d --build
```

- 默认只监听本机 `127.0.0.1:3000`，数据挂载在 `./data`。常用的 `.env` 变量：

  | 变量 | 作用 |
  |---|---|
  | `NOBOT_ADMIN_USERNAME` / `NOBOT_ADMIN_PASSWORD` | 首次启动创建的管理员；创建成功后可以删掉密码 |
  | `NOBOT_ADMIN_RESET=1` | 忘记密码时临时打开，配合新密码重启一次，恢复后改回 `0` |
  | `NOBOT_BIND_IP` / `NOBOT_PORT` | 宿主机监听地址和端口，例如 `0.0.0.0` / `8080` |
  | `TRUST_PROXY=1` | 只在受信任的反向代理后面打开，让登录限流识别真实 IP |
  | `NOBOT_PROXY` / `NOBOT_NO_PROXY` | 出站请求（模型、语音、图片接口）走的代理 |
  | `BUN_IMAGE` / `DEBIAN_MIRROR` / `BUILDKIT_SYNTAX` | 构建时连不上 Docker Hub 或 Debian 源时换成镜像 |

- 更新：拉取新代码后再执行一次 `docker compose up -d --build`

## 账号和用户管理

- 管理员在「设置 → 账号 → 用户管理」里新建用户、重置密码、设为管理员、禁用或删除（删除的数据先移到 `data/deleted-users/`，不会立即清除）；普通用户可以自己改密码
- 每个用户有独立的数据库、素材、语音缓存和扩展，互相看不到对方的角色、会话和 API Key
- 抠图模型这类大文件所有用户共用一份

## 功能

**聊天**
- 流式输出、思考过程（DeepSeek 等）、中止生成；刷新页面或断网后能接着显示，不会丢
- 消息树：重新生成、左右切换 swipe、编辑、删除（连同后面的分支）、从任意一条消息开分支成新会话
- 续写、代写（AI 替你写一条放进输入框）、输入框为空时回车让角色接着说
- 群聊：自然 / 列表 / 轮流 / 手动四种发言顺序，点名发言，静音成员，「只用发言者角色卡」或「合并全员角色卡」
- 会话设置：每个会话可以单独选人设、生成预设、连接（或配置组）、会话世界书、声音分配，编辑作者注释
- 消息操作：不发给模型（单条 / 多选）、编辑思考过程、书签、上移下移（生成交换顺序的新分支）
- 工具调用（跑团）：掷骰、读写会话状态（HP、背包……）。状态跟着消息树走，重新生成或切换分支时自动回退
- 斜杠命令：输入 `/` 弹出补全（`/roll 2d6`、`/sys`、`/bg`、`/imagine`、`/qr`……），用 `|` 串起多条
- 快速回复：输入框上方的一排按钮，发消息或执行命令；全局、按角色或按会话启用，支持自动执行；能导入酒馆的快速回复
- 图片：上传图片给支持看图的模型；不支持看图时用「图片说明」扩展转成文字

**VN 模式**（玩法预设决定一切，内置普通聊天 / 陪伴 / Galgame / RPG / D&D 5e）
- 模型写舞台指令（速记或 XML 两种风格，兼容 MVU 变量写法），普通视图里自动隐藏
- VN 视图：ADV / NVL 版式、打字机、自动、快进、回想、回退、边生成边演、电影模式（上下黑边 + 字幕）
- 群聊多条回复按顺序排队演出，前一位角色没演完不会被下一位打断
- 立绘：表情立绘集和多套服装、导入酒馆立绘包、AI 生成立绘集、拖动缩放、聊天视图侧边立绘、兜底情绪判断；NPC 临时立绘
- 抠图：简单算法、让出图服务直接出透明图（ComfyUI 需要装对应节点）或本地抠图模型（选了才下载）三选一；已有立绘可以重新抠
- 场景：模型换场景时自动切背景，背景库里没有就自动生成一张；`<cg>` 画成 CG 全屏演出，收进角色的 CG 画廊
- 选项按钮、状态面板（好感阶段、飘字、手动修改）、好感阶段触发世界书、存档 / 读档（带缩略图）

**语音和音乐**（「音频」扩展）
- 音频库：上传 BGM 和音效，VN 按舞台指令播放；会话可以设背景音乐；能导入角色卡里带的音频
- 朗读：手动朗读、新回复自动朗读、VN 逐句配音；可选「边生成边朗读」，回复还没写完就先读已经完整的句子
- 引擎：浏览器系统语音、Edge、OpenAI 兼容、ElevenLabs、Fish Audio、MiniMax、火山引擎、GPT-SoVITS、CosyVoice（官方接口或 OpenAI 兼容网关）；Fish Audio 和 CosyVoice 网关能拉取你保存或收藏的声音
- 声音分配：角色卡、会话成员、NPC 分别指定声音，没指定的从声音池里按性别自动分配（能按角色卡推断性别）
- 语气演绎：按台词的情绪、强弱、耳语 / 喊叫和笑声、呼吸等提示，转换成各引擎支持的控制方式；角色可以写自己的演绎风格
- 手机上浏览器拦住自动播放时，顶部会提示点一下开启；切换会话或点「停止」立即停下

**生成预设**（对应酒馆的 AI 响应配置）
- 采样参数：上下文长度、回复长度、流式、温度、Top P / Top K / Min P / Top A、重复 / 频率 / 存在惩罚、种子、停止序列、推理强度、额外请求参数
- Prompt 管理器：拖动调整顺序、开关条目、自定义条目、按深度插入聊天记录、按生成类型触发
- 辅助提示词、角色名发送方式、消息后处理（合并 / 严格交替……）、续写预填充、回复预填充
- 导入 / 导出酒馆预设 JSON
- 界面里标了「未实现」的项目（多回复 n、Logit Bias、联网搜索、图片）会保存但暂不生效

**世界书**
- 关键词（支持 `/正则/`）、可选过滤（四种逻辑）、常驻、概率、递归（三种控制）、包含组（评分、优先、权重）、延迟 / 粘滞 / 冷却（跟着消息树回退）、角色过滤、触发类型、Outlet、最少激活数、向量匹配（需要 embedding 接口）
- 条目可以绑定背景（触发时换背景）、自动化标识（触发快速回复）
- 八种插入位置（角色前后、示例前后、作者注释上下、按深度、Outlet）
- 挂载到全局 / 角色 / 人设 / 会话；全局激活设置（扫描深度、预算、递归轮数、插入策略、最大扫描深度、向量设置）
- 导入 / 导出酒馆世界书 JSON；Prompt 预览里能看到每个条目为什么插入或没插入

**图片和背景**
- 图片生成扩展：OpenAI 兼容（含 gpt-image、Gemini 图片模型）、ComfyUI（自定义工作流）、OpenRouter、A1111 / Forge；9 种模式、风格、按模式覆盖、角色外貌提示词、短标签 / 自然语言两种提示词格式；模型可以通过工具调用生图
- 配置组里可以单独配图片的后端、连接、模型（ComfyUI 工作流）和风格，并拉取模型列表
- 背景库：上传、网址导入、AI 生成、看图自动命名、文件夹、多选批量操作；会话 / 舞台 / 角色或群组默认 / 全局四层；世界书触发或每 N 条回复自动换背景

**跑团（D&D 5e）**
- 人设和角色卡可以带属性卡（六维、熟练、专精、豁免、HP、AC），导出角色卡时一起写进去
- 模型通过工具掷骰、做属性 / 技能检定，结果画成骰子卡片；带检定的选项由我们先掷骰再发送，模型改不了结果
- `<combat>` 指令开启战斗，VN 顶部显示先攻条和 HP

**翻译**（扩展，默认关闭）
- 模型翻译、Google、DeepL、DeepLX、LibreTranslate、Lingva；手动翻译、输入框翻译、`/translate`，或自动翻译回复 / 我的输入
- 原文不丢，可以随时切换；舞台指令翻译后照样生效

**其他**
- 模型接口：覆盖酒馆的全部 Chat Completion Source。Claude / Gemini / Vertex AI / Azure 原生协议（思考过程、图片、工具调用），其余走 OpenAI 兼容接口，自动处理各家的差异
- 配置组：连接 + 模型 + 生成预设 + 正则 + 图片设置打包，可以设为全局默认、绑定角色或在会话里切换
- 剧情总结（扩展，默认关闭）：自动或手动总结较早的对话，注入 Prompt
- 回收站：删除的角色和群组先进回收站，可以恢复
- 角色编辑：全部字段、头像、备选开场白、角色备注、发言积极度、关联世界书、默认人设、性别和声音；导出 PNG / JSON 角色卡
- 多人设：头像、绑定世界书、设为默认；会话可以单独选人设，角色可以指定默认人设
- 日志：每次请求的完整消息、参数、返回、错误、组装报告；消息菜单里「查看请求」直接跳到对应日志
- 扩展：后端扩展可以注册宏、工具、斜杠命令、自定义接口，介入 Prompt 组装和消息入库，前端扩展可以往插槽里加界面。
  内置「正则替换」「图片生成」「音频」「剧情总结」「图片说明」「翻译」，写法参考 `examples/extensions/hello-world`
- 扩展管理：从 Git 地址安装、检查更新、切换分支、卸载，都不用重启；启用前确认权限，更新后权限变多会重新询问；可以添加扩展目录（索引 JSON）浏览和一键安装

## 数据在哪

所有数据都在 `data/` 目录（可以用环境变量 `DATA_DIR` 指定到别的位置）：

```
data/system.db          账号和登录会话
data/users/<用户名>/     每个用户自己的数据：app.db（SQLite）、assets/（头像、立绘、背景、音频、聊天图片）、
                        tts-cache/（语音缓存）、extensions/（安装的扩展）
data/models/            所有用户共用的模型文件（比如抠图模型）
```

备份就是停掉服务后复制整个 `data/` 目录。从单用户的旧版本升级时，第一次启动会把旧的 `data/app.db` 等文件自动移到管理员名下。

## 开发

```bash
bun test              # 全部测试（core 的单元测试 + 后端接口和生成流程的端到端测试）
bun run typecheck     # 所有包的类型检查
bun run lint          # Biome 代码检查
bun run db:generate   # 修改 apps/server/src/db/schema.ts 后生成迁移
bun scripts/mock-llm.ts  # 模拟模型（端口 3999，连接填 http://127.0.0.1:3999/v1、Key 填 sk-test），不花钱调试
                         # 消息含「VN」时回复带舞台指令（含 <cg>）；也模拟图片接口和 ComfyUI
```

不能监听端口或不想联网时，测试加上 mock 开关：

```bash
MOCK_LLM_FETCH=1 EXT2_FETCH_MOCK=1 IMG3_FETCH_MOCK=1 BACKGROUND_FETCH_MOCK=1 TTS_FETCH_MOCK=1 bun test
```

`fixtures/` 里有测试用的样例数据：4 张中文角色卡、一本 20 条的酒馆格式世界书、一个酒馆格式的生成预设。

目录结构：

```
packages/shared   前后端共用的类型和 Zod 校验规则（接口契约）
packages/core     纯逻辑：Prompt 组装、世界书扫描、宏、群聊发言顺序、角色卡 / 酒馆格式互转、消息树、VN 舞台指令
apps/server       Bun + Hono 后端：账号、数据库、接口（约定见 apps/server/API.md）、生成任务、工具、扩展、日志
apps/web          React 前端
```
