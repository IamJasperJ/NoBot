# AI-Parter

一个轻量、快速的 AI 角色扮演 / 陪伴 / 跑团应用。兼容酒馆（SillyTavern）的角色卡、世界书和生成预设，只保留核心功能，长对话也不卡。

设计文档：<https://claude.ai/code/artifact/4fbca930-93b0-4d93-a6fe-5fffca832518>

## 快速开始

需要 [Bun](https://bun.sh) 1.4 以上（macOS：`brew install oven-sh/bun/bun`）。

```bash
bun install
bun run dev
```

浏览器打开 <http://localhost:5173>，左边一列是导航：

1. **连接**：添加一个 OpenAI 兼容接口（DeepSeek、OpenRouter、各类中转站都行），点「测试并获取模型」确认能连上
2. **人设**：改成你想在故事里用的名字（角色卡里的 `{{user}}` 会替换成它），可以建多个人设
3. **角色**：导入酒馆的 PNG / JSON 角色卡，或者新建一个；卡里自带的世界书会自动导入
4. **聊天**：点角色 → 「新建会话」开始聊天；点「群聊」可以把几个角色拉进一个群

### 日常使用（生产模式）

```bash
bun run build   # 打包前端，只需在代码更新后执行一次
bun start       # 只启动一个进程，打开 http://127.0.0.1:3000
```

想用手机访问（同一个局域网）：`HOST=0.0.0.0 bun start`，然后手机打开 `http://电脑的局域网IP:3000`。
注意：这样同一网络里的任何人都能用你配置的 API Key，只在自己家里的网络这样做。

## 功能

**聊天**
- 流式输出、思考过程（DeepSeek 等）、中止生成；刷新页面或断网后能接着显示，不会丢
- 消息树：重新生成、左右切换 swipe、编辑、删除（连同后面的分支）、从任意一条消息开分支成新会话
- 续写、代写（AI 替你写一条放进输入框）、输入框为空时回车让角色接着说
- 群聊：自然 / 列表 / 轮流 / 手动四种发言顺序，点名发言，静音成员，「只用发言者角色卡」或「合并全员角色卡」
- 会话设置：每个会话可以单独选人设、生成预设、连接、会话世界书，编辑作者注释
- 工具调用（跑团）：掷骰、读写会话状态（HP、背包……）。状态跟着消息树走，重新生成或切换分支时自动回退

**生成预设**（对应酒馆的 AI 响应配置）
- 采样参数：上下文长度、回复长度、流式、温度、Top P / Top K / Min P / Top A、重复 / 频率 / 存在惩罚、种子、停止序列、推理强度、额外请求参数
- Prompt 管理器：拖动调整顺序、开关条目、自定义条目、按深度插入聊天记录、按生成类型触发
- 辅助提示词、角色名发送方式、消息后处理（合并 / 严格交替……）、续写预填充、回复预填充
- 导入 / 导出酒馆预设 JSON
- 界面里标了「未实现」的项目（多回复 n、Logit Bias、联网搜索、图片）会保存但暂不生效

**世界书**
- 关键词（支持 `/正则/`）、可选过滤（四种逻辑）、常驻、概率、递归（三种控制）、包含组、延迟、角色过滤、触发类型、Outlet
- 八种插入位置（角色前后、示例前后、作者注释上下、按深度、Outlet）
- 挂载到全局 / 角色 / 人设 / 会话；全局激活设置（扫描深度、预算、递归轮数、插入策略）
- 导入 / 导出酒馆世界书 JSON；Prompt 预览里能看到每个条目为什么插入或没插入

**其他**
- 角色编辑：全部字段、头像、备选开场白、角色备注、发言积极度、关联世界书、默认人设；导出 PNG / JSON 角色卡（酒馆可读）
- 多人设：头像、绑定世界书、设为默认；会话可以单独选人设，角色可以指定默认人设
- 日志：每次请求的完整消息、参数、返回、错误、组装报告；消息菜单里「查看请求」直接跳到对应日志
- 扩展：后端扩展可以注册宏、工具，介入 Prompt 组装和消息入库；内置「正则替换」扩展；
  第三方扩展放在 `data/extensions/<目录>/index.ts`（写法见 `apps/server/src/extensions/types.ts`）

## 还没做

- 世界书的粘滞 / 冷却 / 最少激活数 / 向量匹配、群聊自动模式、多账号登录
- Claude / Gemini 原生接口（目前只支持 OpenAI 兼容接口）
- 导入酒馆聊天记录、TTS、生图、前端扩展（自定义界面）

## 数据在哪

所有数据都在 `data/` 目录：`data/app.db`（SQLite 数据库）和 `data/assets/avatars/`（头像）。
备份就是复制整个 `data/` 目录。也可以用环境变量 `DATA_DIR` 指定到别的位置。

## 开发

```bash
bun test              # 全部测试（core 的单元测试 + 后端接口和生成流程的端到端测试）
bun run typecheck     # 所有包的类型检查
bun run lint          # Biome 代码检查
bun run db:generate   # 修改 apps/server/src/db/schema.ts 后生成迁移
bun scripts/mock-llm.ts  # 模拟模型（端口 3999，连接填 http://127.0.0.1:3999/v1、Key 填 sk-test），不花钱调试
```

`fixtures/` 里有测试用的样例数据：4 张中文角色卡、一本 20 条的酒馆格式世界书、一个酒馆格式的生成预设。

目录结构：

```
packages/shared   前后端共用的类型和 Zod 校验规则（接口契约）
packages/core     纯逻辑：Prompt 组装、世界书扫描、宏、群聊发言顺序、角色卡 / 酒馆格式互转、消息树计算
apps/server       Bun + Hono 后端：数据库、接口（约定见 apps/server/API.md）、生成任务、工具、扩展、日志
apps/web          React 前端
```
